# 1 pertanyaan wawancara React Native

1. **Apa itu React Native?** React Native adalah _framework_ kode terbuka yang dibuat oleh Meta yang mengizinkan pengembang untuk membuat aplikasi mobile antar-platform dengan menggunakan JavaScript dan React.
2. **Apa perbedaan utama dari React dengan React Native?** React adalah pustaka untuk membangun antarmuka web menggunakan elemen HTML (DOM), sementara React Native adalah kerangka-kerja untuk membangun aplikasi perangkat bergerak menggunakan komponen antarmuka pengguna asli perangkat bergerak.
